# What is DBT?
  * ETL - Extract Transfrom Load
  * DBT is - Transfrom in ETL process

# WHY?
    * Modularity
    * Templating - Jinja Templates

# DBT Platforms
    * DBT CORE : CLI TOOL OPENSOURCE
    * DBT CLOUD : MANAGED PRODUCT ON. TOP OF DBT CORE - MANAGED BY DBT
    * DBT CANVAS : GUI TOOL

# BACKBONE OF DBT
    * DBT MODELS : CODING PART OF DBT
